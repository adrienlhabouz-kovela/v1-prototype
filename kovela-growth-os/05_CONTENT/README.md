## TL;DR

Ce dossier pilote le contenu qui alimente l'acquisition : **SEO** (capter
l'intention des chirurgiens), **LinkedIn** (autorité du fondateur + marque), et
**recyclage** (un actif produit plusieurs formats). Le contenu n'est pas un but :
il existe pour remplir le pipeline (`03_CRM/`) et générer des RDV.

## Objectif

Construire un flux régulier de contenu qui positionne KOVELA comme l'extension
opérationnelle de référence du post-op, et qui fait entrer des chirurgiens
qualifiés dans le pipeline sans dépendre de l'outbound seul.

## Action attendue

Le Growth Ops sait, chaque semaine : quoi produire, où le publier, comment le
recycler, et comment il convertit vers une landing ou un RDV.

## KPI

- Visiteurs SEO qualifiés / mois et conversions vers landing.
- Impressions + taux d'engagement LinkedIn (Adrien + page KOVELA).
- Nombre de RDV attribués au contenu (source `contenu` dans le CRM).
- Ratio d'actifs recyclés (1 actif → N formats publiés).

## Process — Les briques du dossier

| Fichier | Rôle |
|---|---|
| `SEO_STRATEGY.md` | Capter l'intention de recherche, contenus piliers, conversion |
| `LINKEDIN_ADRIEN.md` | Autorité du fondateur, ligne éditoriale, formats |
| `LINKEDIN_KOVELA.md` | Page entreprise : marque, preuves, social proof |
| `EDITORIAL_CALENDAR.md` | Cadence, thèmes, workflow de production |
| `CONTENT_RECYCLING.md` | Transformer un actif en chaîne de formats |

### Comment ce dossier alimente l'acquisition

1. **SEO** capte les chirurgiens en recherche active (intention haute) → landing → RDV.
2. **LinkedIn** crée la familiarité et l'autorité avant l'outbound → réchauffe `02` / `07`.
3. **Recyclage** multiplie la portée sans multiplier l'effort de production.
4. Tout RDV généré est tracé dans le CRM avec sa source pour mesurer le ROI réel.
